1
Install everything you need first
One time only — 30 minutes
step 1
Install Python 3.10install
Go to python.org/downloads → download Python 3.10.x → install it. During install tick the checkbox that says "Add Python to PATH". This is important.
Why 3.10 specifically? TensorFlow and MediaPipe work best on 3.10. Don't install 3.12 or 3.13 — they will break things.
step 2
Install VS Codeinstall
Go to code.visualstudio.com → download → install. This is your code editor. Install the Python extension inside VS Code (Extensions tab → search Python → install).
step 3
Install Gitinstall
Go to git-scm.com/downloads → download → install with all default settings. Git is what lets you clone repos.
step 4
Install PostgreSQLinstall
Go to postgresql.org/download → download → install. During install set password as "admin123" (remember this). Default port 5432 is fine. Also install pgAdmin (comes with it) — that's your database visual tool.

3
Run the ASL repo — confirm the AI works
30 minutes — do this before anything else
step 10
Create a virtual environmentimportant
In your terminal, go inside the ASL folder and create an isolated Python environment. This prevents library conflicts.
cd Sign-Language-To-Text-and-Speech-Conversion python -m venv venv
Then activate it:
# Windows: venv\Scripts\activate # Mac/Linux: source venv/bin/activate
You'll see (venv) appear at the start of your terminal line. That means it's active.
step 11
Install all required librariespaste in terminal
pip install -r requirements.txt
If requirements.txt doesn't exist in this repo, install manually:
pip install opencv-python mediapipe tensorflow keras numpy pyttsx3 Pillow
This will take 5–10 minutes. Let it finish.
step 12
Run it and testmoment of truth
python app.py
A webcam window should open. Do ASL signs A, B, C in front of your camera. You should see letters appear on screen and hear them spoken. If this works — you have your AI core running.
If it works, take a screen recording. This is your demo for the guide meeting.
If it crashes with a library error, screenshot the error and message me — I'll tell you exactly what to fix.
4
Create YOUR Django project — the Silent Talk shell
1–2 days — this is your original work
step 13
Go back to the SilentTalk root folder and install Djangoterminal
cd .. python -m venv silenttalk_env # activate it: silenttalk_env\Scripts\activate # Windows source silenttalk_env/bin/activate # Mac pip install django psycopg2-binary pillow tensorflow mediapipe opencv-python pyttsx3 gTTS
step 14
Create the Django projectyour project starts here
django-admin startproject silenttalk cd silenttalk python manage.py startapp recognition python manage.py startapp users python manage.py startapp learn
You now have a Django project called silenttalk with 3 apps: recognition (AI webcam page), users (login/signup), learn (ISL learning module).
step 15
Connect PostgreSQL to Djangoedit settings.py
Open silenttalk/settings.py. Find the DATABASES section and replace it with:
DATABASES = { 'default': { 'ENGINE': 'django.db.backends.postgresql', 'NAME': 'silenttalkdb', 'USER': 'postgres', 'PASSWORD': 'admin123', 'HOST': 'localhost', 'PORT': '5432', } }
Now open pgAdmin → create a new database called silenttalkdb. Then run:
python manage.py migrate python manage.py createsuperuser
step 16
Copy the AI model from the cloned repo into Djangocopy-paste
From Sign-Language-To-Text-and-Speech-Conversion folder, copy the model file (model.h5 or model.pkl) and the prediction function into your Django project:
SilentTalk/ └── silenttalk/ └── recognition/ ├── models_ai/ │ └── model.h5 ← paste here (from cloned repo) ├── ai_engine.py ← create this file └── views.py
In ai_engine.py, copy the predict function from the cloned repo — the part that takes a frame and returns a letter. That is the only code you "write" — and you're copying it.
step 17
Add AJAX webcam view + jQuery live updateM5 syllabus done
Create recognition/templates/recognition.html with a webcam feed and jQuery that calls your Django view every 500ms and updates the detected letter on screen in real time. Covers your entire Module 5 (jQuery + AJAX) requirement.
// In recognition.html — this is all jQuery AJAX you need: setInterval(function() { $.post('/predict/', {frame: capturedFrame}, function(data) { $('#detected-text').append(data.letter); }); }, 500);
